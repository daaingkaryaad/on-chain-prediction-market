# On-Chain Prediction Market

A decentralized prediction market protocol built with Solidity, Foundry, React, and Chainlink.

## Features
- Binary prediction markets
- CPMM AMM
- ERC1155 outcome shares
- DAO governance
- ERC4626 vault
- Chainlink oracle integration
- L2 deployment

## Stack
- Solidity
- Foundry
- React
- Wagmi
- The Graph
